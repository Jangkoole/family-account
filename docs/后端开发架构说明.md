**填充顺序**：
1. 先填充 `entity/`下的`xxx.java`（对应你做的模块），对应数据库的表（e.g. `User.java`对应数据库`user`表）
2. 接着填充 `Mapper/`层，定义数据库操作
3. 再接着填充 `DTO/`层，定义前后端传输的数据格式
4. 再接着填充 `Service/`层，写四个DTO类，定义前后端传输的数据格式
5. 最后填充`Controller/`层，对外暴露后端接口


==依赖添加==：
`pom.xml`中的`dependencies`项，只添加自己用上的，不要多加多余的依赖。添加规范：添加依赖后最好添加注释，版本号最好不要写死在`dependency`中，统一写在 `properties`里以便于管理：
```xml
<properties>  
    <java.version>21</java.version>  
       <kotlin.version>2.2.20</kotlin.version>  
       <mybatis-plus.version>3.5.10</mybatis-plus.version>  
       <sa-token.version>1.39.0</sa-token.version>
       
 ...
 
<!--entity/User.java中对 MyBatis-Plus的依赖-->  
<dependency>  
    <groupId>com.baomidou</groupId>  
    <artifactId>mybatis-plus-spring-boot3-starter</artifactId>  
    <version>${mybatis-plus.version}</version>  
</dependency>  
  
<!--登录功能用到的Sa-Token依赖-->  
<dependency>  
    <groupId>cn.dev33</groupId>  
    <artifactId>sa-token-spring-boot3-starter</artifactId>  
    <version>${sa-token.version}</version>  
</dependency>
```
