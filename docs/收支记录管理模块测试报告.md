收支记录管理模块后端接口测试报告
一、测试环境
1.后端服务：Spring Boot 3.5.14 + JDK 21，运行于 http://localhost:8090
2.数据库：MySQL 8.x（云服务器 8.153.163.48:3306/family_account）
3.测试工具：Apifox（已配置环境变量 baseUrl、token，全局请求头 Authorization: {{token}}）

二、测试数据准备
1.注册测试账号
POST /user/register

{
  "account": "xgh@qq.com",
  "password": "654321",
  "nickname": "xx"
}

2.登录获取token
POST /user/login

{
  "account": "xgh@qq.com",
  "password": "654321"
}
将响应中的token设置为全局环境变量

三、接口测试
3.1新增收支记录（POST /bill/add）
a.正常支出记录
请求体：{"type":"EXPENSE","categoryId":1,"amount":25.50,"date":"2026-05-29","note":"午饭","visible":"PRIVATE"}
结果：code:200,返回data.id

b.正常收入记录
请求体：{"type":"INCOME","categoryId":9,"amount":5000,"date":"2026-05-29","note":"工资","visible":"PRIVATE"}
结果：code:200，返回记录ID

c.金额为负数
请求体：{"type":"EXPENSE","categoryId":1,"amount":-10,"...}
结果：code:500，message 包含“金额必须大于0”

d.分类ID不存在
请求体：{"type":"EXPENSE","categoryId":999,"amount":10,...}
结果：code:500，message “分类不存在”

e。独立用户设置FAMILY可见
请求体：{"visible":"FAMILY",...}
结果：后端强制改为 PRIVATE，记录仍为 PRIVATE

3.2修改收支记录（PUT /bill/update）
a.正常修改（改金额、备注）
请求体：{"id":1,"amount":30.00,"note":"新备注"}
结果：code:200，message “修改成功”

b.修改不存在的记录
请求体：{"id":999,"amount":30.00,"note":"新备注"}
结果：code:404，message “记录不存在”

c.修改其他用户的记录
请求体：{"id":1,"amount":30.00,"note":"新备注"}
结果：code:403，message “没有权限修改其他用户的记录”

d. 独立用户修改 visible 为 FAMILY
请求体：{"id":1,"visible":"FAMILY"}
结果：code:500，message “独立用户不能设置FAMILY可见”

3.3删除收支记录（DELETE /bill/delete/{id}）
a.正常删除
请求体：{"id":1}
结果：code:200，message “删除成功”

b.删除不存在的记录
请求体：{"id":999}
结果：code:404，message “记录不存在”

c.删除其他用户的记录
请求体：{"id":1}
结果：code:403，message “没有权限删除其他用户的记录”

3.4查询收支记录列表（GET /bill/list）
a.page=1&pageSize=10
结果：返回分页数据，total>0，列表包含最近记录

b.startDate=2026-05-01&endDate=2026-05-31
结果：返回分页数据，total>0，列表包含2026年5月1日至5月31日的记录

c.type=EXPENSE
结果：返回分页数据，total>0，列表包含支出记录

d.type=INCOME
结果：返回分页数据，total>0，列表包含收入记录

e.categoryId=1
结果：返回分页数据，total>0，列表包含分类ID为1的记录

f.无任何参数
结果：默认返回第1页，每页20条记录

3.5获取收支记录详情（GET /bill/detail/{id}）
a.存在的记录 id=162
结果：返回记录详情，包含所有字段

b.不存在的 id
code:500，message “记录不存在”

c.他人记录（无权限）
code:403，message “没有权限查看其他用户的记录”

3.6修改记录可见范围（PUT /bill/visible）
a.独立用户将 PRIVATE 改为 PRIVATE
请求体：{"ids":[162],"visible":"PRIVATE"}
结果：code:200，可见范围不变

b.独立用户尝试改为 FAMILY
请求体：{"ids":[162],"visible":"FAMILY"}
结果：code:500，message “独立用户不能设置FAMILY可见”

c.批量修改（两个id）
请求体：{"ids":[162,163],"visible":"FAMILY"}
结果：code:200，两记录均变为 PRIVATE

四、测试结论
所有核心功能接口（新增、修改、删除、查询列表、详情、可见范围修改）均已通过测试，业务逻辑与权限控制符合需求文档要求。

收支记录管理模块前端接口测试报告

二、测试用例及结果
2.1页面加载与列表展示
登录后点击侧边栏“收支记录”
结果：进入 /bill 页面，显示筛选栏、表格、分页组件

表格自动加载第1页数据
结果：显示当前用户的所有账单记录（如有多条）

表格为空时显示“No Data”
结果：显示友好提示“暂无收支记录”

2.2新增账单
点击“+新增账单”按钮
结果：弹出表单弹窗，标题“新增账单”

不填任何字段，点击“确定”
结果：表单验证提示“请输入...”，不提交请求

填写所有必填项（支出、餐饮、金额50、日期当天、备注可选），点击“确定”
结果：表单验证通过，提交请求，新增记录显示在表格中

独立用户设置“可见范围”为“家庭成员可见”
结果：后端强制改为 PRIVATE，记录仍为 PRIVATE

2.3编辑账单
点击表格中的“编辑”按钮
结果：弹出表单弹窗，标题“编辑账单”

填写修改后的金额、备注，点击“确定”
结果：表单验证通过，提交请求，记录在表格中更新

修改不存在的ID（后端返回错误）
结果：弹出错误提示“记录不存在”

2.4删除账单
点击某行的“删除”按钮
结果：弹出确认删除弹窗，提示“确认删除吗？”

点击“确认”
结果：提交删除请求，记录从表格中移除

点击“取消”
结果：弹窗关闭，不执行删除操作

2.5单条修改可见范围
在表格某行点击“可见范围”下拉菜单，选择“仅自己可见”
结果：发送请求，成功后表格刷新，该行可见范围标签变为“仅自己可见”

独立用户选择“家庭成员可见”
结果：后端返回错误“独立用户不能设置FAMILY可见”，前端提示错误

2.6批量修改可见范围
勾选表格前两行，点击“批量修改可见范围”
结果：弹出弹窗，显示“批量修改可见范围”

选择“仅自己可见”，点击“确定”
结果：发送请求，成功后表格刷新，两行可见范围标签变为“仅自己可见”

不勾选任何行直接点击按钮
结果：弹窗关闭，不执行任何操作

2.7筛选查询

结果：表格显示2026年5月1日至5月31日的记录

结果：表格显示支出记录

结果：筛选栏重置为默认值，表格显示所有记录

2.8分页功能
当记录数超过一页时，点击“下一页”
结果：表格显示下一页记录

修改每页条数（10/20/50）
结果：表格显示每页记录数变化

跳转到指定页码
