# 约定说明

**Base URL：** `http://服务器公网IP:8090`
**请求格式：** JSON
**响应格式：** 统一返回以下结构：

```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```

**认证方式：** 除注册、登录接口外，所有接口请求头需携带：

```
Authorization: token值
```

**常用状态码：**

- 200：成功
- 400：请求参数错误
- 401：未登录或token失效
- 403：无权限
- 500：服务器错误
