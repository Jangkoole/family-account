1. 后端
+ Spring Boot 3.5.14 -- 核心框架，简化Java EE开发
+ MyBaris-Plus -- ORM框架，操作数据库比原生 JDBC方便很多
+ MySQL 8.x -- 数据库 (部署在云服务器上)
+ Sa-Token -- 登录认证
+ Maven -- 依赖管理


2. 前端
+ Vue3 + Element Plus -- 主流组合
+ ECharts -- 做收支统计图表
+ Axios -- 前后端接口调用

前后端交互：JSON格式


3. 架构设计
```text
前端 (Vue3)  <——HTTP/JSON——>  后端 (Spring Boot)  <——JDBC——>  MySQL
```

后端内部按标准分层：
+ Controller层：接收前端发来的HTTP请求，调用Service层处理，返回统一格式的JSON给前端，本身不处理任何业务逻辑。
+ Service层：负责所有业务逻辑（比如按月汇总，按成员统计），调用Mapper层拿数据，处理完后返回给Controller
+ Mapper层：只负责和数据库打交道，写 SQL 或用 MyBatis-Plus提供的方法查数据。
+ Entity/DTO层：Entity是和数据库表一一对应的java类，一张表对应一个.java文件；DTO 是前后端之间传输数据用的统一类
