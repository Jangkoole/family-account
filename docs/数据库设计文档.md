# 设计大纲：
1. **用户相关**
- `user` 用户表

2. **家庭组相关**
- `family` 家庭组表
- `family_member` 家庭成员关系表
- `family_apply` 加入家庭申请表

3. **收支分类相关**
- `category` 分类表
- `category_apply` 分类审核申请表

4. **收支记录相关**
- `bill` 收支记录表

---

共**7张表**，覆盖所有模块的数据存储需求。
每张表设计时需要包含：字段名、数据类型、是否为空、默认值、说明，以及表与表之间的外键关系。
